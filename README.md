# Phase 1: Project Initialization and Planning

## Project Title
**Electric Vehicle Market Analysis Using Tableau**

## Project Overview
The project focuses on analyzing the electric vehicle (EV) market using Tableau. It aims to understand sales trends, vehicle performance, battery technologies, manufacturers, and environmental impact through data visualization.

## Objectives
- Analyze electric vehicle sales trends.
- Compare EV manufacturers and vehicle categories.
- Study battery types and battery technology performance.
- Analyze vehicle range, charging, and efficiency.
- Understand the environmental impact of electric vehicles.
- Create an interactive Tableau dashboard.

## Tools and Technologies
- Tableau
- Microsoft Excel / CSV
- GitHub
- Data visualization and analysis

## Expected Outcome
An interactive Tableau dashboard that presents meaningful insights into the electric vehicle market and supports data-driven decision-making.
